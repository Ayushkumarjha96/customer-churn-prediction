# Project Pipeline

Use this notebook order when you want the project in Jupyter:

1. Load and inspect raw data
2. Clean `TotalCharges`
3. Create business features
4. Analyze churn by contract, tenure, payment, internet service and support
5. Train Logistic Regression, Random Forest and XGBoost
6. Compare ROC-AUC, precision, recall and F1
7. Tune the decision threshold for retention capacity
8. Add SHAP explanations
9. Export customer risk scores
10. Connect the model to the Streamlit app
